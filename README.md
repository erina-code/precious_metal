# 貴金属買取管理システム
金・プラチナ・シルバーなどの貴金属買取業務を管理するWebアプリケーションです。
顧客情報の管理から買取受付、買取明細の登録までを行うことができます。

## 使用技術
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## 主な機能
### 顧客管理
- 顧客情報の登録・一覧表示・編集・削除

### 買取管理
- 顧客情報を検索して買取受付
- 買取情報の一覧表示・編集・削除

### 買取明細管理
- 1回の買取受付に対して複数明細を登録
- 貴金属の種類に応じた品位の選択
- 重量と単価から買取金額を自動計算
- 明細金額の合計を買取情報に反映

## 工夫した点・苦労した点
- 複数の買取明細を一度に登録する処理では、
  配列で受け取ったデータを1件ずつ取り出して登録する方法を学びました。
- 複数明細の登録時に一部だけ登録されることを防ぐため、
  トランザクション処理を実装しながら学びました。
- 金属の種類により選択できる品位も異なるため、
  JavaScriptで表示を切り替える処理を実装しながら学びました
